## Acknowledgements

Special thanks to:

- **[NexusBV](https://nexusbv.net)** - a modern and smooth boardview viewer
- **[OpenBoardView](https://github.com/OpenBoardView)** - an open-source boardview viewer
- **[SumatraPDF](https://github.com/sumatrapdfreader)** - an open-source PDF reader
- **[VoltageDividerTool](https://github.com/mhqb365/VoltageDividerTool)** - a voltage divider calculation tool

This project uses these tools to provide a multi-format file viewing experience in a single application

## Features

- **Multi tab**: Open multiple files at the same time
- **Multi viewer**: View boardview files with 3 options: **NexusBV**, BoardViewer, OpenBoardView
- **PDF viewer**: View PDF files with integrated SumatraPDF
- **Voltage Divider Calculator**: Calculate voltage divider values
- **Search files**: Search for files in a selected folder or drive
- **Directory tree**: Browse the directory tree of a selected folder or drive
- **Recent files**: Quickly reopen recently opened files

## System Requirements

- Windows 10/11
- [.NET 8.0 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

## Installation

1. Download `MultiBoardViewer_<version>.zip` from the [Releases](https://github.com/mhqb365/MultiBoardViewer/releases) page
2. Extract the archive and run `MultiBoardViewer.exe`

## Usage

- **Search files**: Select a folder or drive that contains your files using the folder icon -> type a file name in the search box -> click a file to open it with NexusBV, or right-click to open it with another viewer
- **Directory tree**: Select a folder or drive that contains your files using the folder icon -> click a file to open it with NexusBV, or right-click to open it with another viewer
- **Recent files**: View and reopen recently opened files
- **Drop file or Open file**: Drag and drop a file into the lower-right area of the app, or click **+ Open file** and select the file you want to open
